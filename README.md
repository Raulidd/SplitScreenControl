#  SplitScreenControl

**Split-screen multiplayer-style control for Spaceflight Simulator 1.6.0.**

Split your screen and **control two rockets simultaneously**, even when they are in completely different locations.

##  Features

*  Control two rockets at the same time
*  Real split-screen camera view
*  Works across different locations and celestial bodies
*  Quickly switch between your primary and secondary rocket
*  Handles rocket destruction automatically
*  Compatible with the in-game map
*  Camera and zoom controls work with both views

##  How to use

1. Have **at least two rockets** in your game.
2. Press **`Alt + C`** to open the SplitScreenControl menu.
3. Select the rocket you want to use as your **secondary rocket**.
4. That's it — split-screen will start automatically.

To stop using split-screen, simply press **`Alt + C`** again.

##  Installation

Install the mod into your **Spaceflight Simulator 1.6.0** mods folder.

> Make sure you are using the correct version of Spaceflight Simulator.

##  Example

Control two rockets simultaneously, even if one is on Earth and the other is somewhere else.
